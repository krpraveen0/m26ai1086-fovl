# Class materials

Each class gets one numbered directory:

```text
class_NN_short-topic/
├── README.md       # learning objectives, summary, and follow-up work
├── notes/          # PDFs, slides, and reading notes
├── notebooks/      # exploratory notebooks and demonstrations
├── src/            # reusable code extracted from the class
└── tests/          # checks for code in src/
```

Use the next available number for a new session. Keep experiments close to the
class that introduced them; move code to a shared top-level package only when
multiple classes genuinely reuse it.
